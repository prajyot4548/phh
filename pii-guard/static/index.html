    Want this to check automatically every time you turn the PC on?

    PII Guard runs as a normal app — it can't switch itself on at install time, but you can make Windows open it for you every time you log in:

    1. Press Win + R, type shell:startup, press Enter.
    2. In that folder, create a shortcut to a file named start.bat containing one line: python app.py (place it in this project folder).
    3. From now on, PII Guard starts quietly in the background each time you log in — open http://127.0.0.1:5000 to check it.
